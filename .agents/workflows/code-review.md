# Workflow: Review Changes

Review for:
- Requirement and acceptance-criteria coverage.
- Architecture consistency and unnecessary dependencies.
- Security flaws, missing authorization, unsafe uploads, and secret leakage.
- Data integrity, migration safety, and query performance.
- API validation, error contracts, and backwards compatibility.
- SEO metadata, canonical/hreflang correctness, and structured-data accuracy.
- English/Urdu completeness and RTL correctness.
- Accessibility, keyboard behavior, mobile layout, and visual consistency with references.
- Tests that cover changed behavior.

Report findings by severity with file/line references where possible. Do not claim approval if checks were not run.
