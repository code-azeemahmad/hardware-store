# Workflow: Plan a Feature

1. Read `AGENTS.md` and relevant product/technical documents.
2. Inspect the current codebase and existing tests.
3. Identify user outcome, scope, dependencies, risks, and acceptance criteria.
4. Check whether the feature conflicts with confirmed decisions.
5. Break the work into small ordered tasks.
6. Identify required API, database, UI, SEO, localization, and security changes.
7. Update the task register before implementation.
8. Ask for clarification if a required business rule is unknown.
9. Do not write implementation code until the plan is accepted when the request is planning-only.
