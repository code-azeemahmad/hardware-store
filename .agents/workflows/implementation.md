# Workflow: Implement a Feature

1. Read `AGENTS.md`, the relevant docs, and the active task.
2. Inspect existing code, patterns, and tests before editing.
3. For UI tasks, inspect relevant `reference/` screenshots and note layout details.
4. Implement the smallest coherent vertical slice.
5. Add/update tests and translations for English and Urdu where applicable.
6. Verify authorization, validation, error states, accessibility, and responsive behavior.
7. Run relevant tests, linting, type checks, and builds; inspect actual output.
8. Update API/schema/architecture docs if contracts changed.
9. Update task status and progress with evidence.
10. Summarize changed files, verification performed, and remaining risks.
