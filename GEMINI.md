# Antigravity / Gemini Workspace Instructions

Use `AGENTS.md` as the shared project instruction source. Read it before making changes.

For task-specific work, read the relevant documents under `docs/` and the active task in `project-management/tasks.md`.

## Antigravity-specific guidance

- Persistent project rules are maintained in `.agents/rules/`.
- Reusable procedures are maintained in `.agents/workflows/`.
- Keep rules concise, actionable, and consistent with `AGENTS.md`.
- Do not assume a workflow file is automatically invoked; follow it when the task calls for it.
- Inspect `reference/` screenshots before frontend visual implementation.
- Do not start implementation when asked only to plan, scaffold documentation, or review.
- Never invent missing business information or mark unverified work complete.
